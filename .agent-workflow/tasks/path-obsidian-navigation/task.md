# 学习规划仿 Obsidian 导航与文件树交互

## Goal

调整学习规划工作区的导航层级和文件树操作，使顶部承担侧栏开关、文件列表、搜索与右侧文件标签；左侧竖栏只保留导师和知识图谱。第二行对齐文件操作与文档导航，提供阅读／编辑切换，并补齐 Markdown 点击显露语法。

## Scope

- In scope: `src/pages/Path/`、`src/store/modules/pathStore.ts`、`src/types/path.ts`
- In scope: `tests/path-layout-ui.py`、`tests/path-editor-ui.py`、`tests/path-tabs-ui.py`、`tests/path-markdown-interactions-ui.py`
- Out of scope: 后端接口、数据库结构、已有文件和文件夹数据、简历与知识广场

## Deliverables

- 顶部文件/搜索导航与精简后的左侧竖栏
- 居中的文件工具栏与全部展开/折叠
- 知识图谱退出后文件可正常打开
- 图谱入口重复点击保持显示、顶部文件/搜索只切换左栏，标签与面包屑统一为“知识图谱”
- 可拖动分隔线、左拖折叠与拖回展开，限制主区最小空间并同步开关图标
- 默认侧栏加宽至 300px，按钮开合有平滑过渡，顶部边界随实际宽度同步；拖动保持直接响应
- 文件标签与文件/搜索同一行；文档返回/前进与左侧文件工具栏同一行，右端提供阅读/编辑开关
- 文件与图谱标签默认等宽 200px，拥挤时均分可用空间并以 200ms 过渡缩放，不出现横向滚动条
- 首次加载工作区和从其他页面返回时已有标签直接显示，初始化测宽和恢复数据不触发动画；页面内新增与关闭仍平滑过渡
- 标签栏最右侧固定下拉箭头，打开菜单后选择“全部关闭”才关闭所有标签；保留文件内容、空白状态持久化及新建能力
- 阅读模式只读；标题/行内样式原生显露，链接补齐地址显露；引用/列表/表格原生编辑，不再使用块级源码输入框。编辑操作菜单提供取消当前格式、在当前块后继续输入、原生 Markdown 源码编辑，保留撤销/重做与快速切换输入
- 引用采用中性色浅底、留白和轻微圆角，无高亮竖线/外框，编辑与阅读、明暗主题一致
- 点击引用在当前段落或子块旁显露可删除的 `>`；删除只取消当前引用层，保留正文、内联格式、代码、列表与嵌套引用，支持撤销/重做和模式切换
- 空行 `- + 空格` 立即创建列表；点击当前无序列表项显示可编辑前缀，删除前缀只取消当前项的格式并保留文字、相邻项和嵌套内容
- 代码块结束围栏可直接点击，或从正文末尾按下键到达；围栏处回车在代码块后继续普通输入，退格/删除取消代码格式并保留代码文字
- 阅读时切换文件再回编辑仍保持正文居中；侧栏和窗口宽度变化时自动调整正文列
- 左侧顶部导航和文件操作栏无多余横线；顶部与下方拖动竖线对齐，折叠时隐藏失去对应关系的边界
- 构建及宽窄视口浏览器验收证据

## Risks

- 导航层级调整可能导致侧栏折叠状态和内容面板不同步
- 图谱标签状态可能继续遮挡当前文件编辑器
- 全部展开会写入工作区状态，需保持保存队列兼容
- 源码编辑与即时渲染之间的转换可能遗漏末次输入、重复替换块或清空撤销记录，需检查模式与文件切换后的实际保存内容
