## Review 与实际运行发现的修复

1. 规格审查发现旧快照会丢失更早首次观测：统一合并最早时间，补反向到达、持久化和重复重试验证。
2. 恢复步骤与预建 schema 冲突：先确认目标空 schema，只移除 TOC 中一条 schema 创建项，保留其余顺序，不清空或删除目标。
3. 质量审查复现 CLI leader 先退导致后代残留：单一进程组管理函数保留强制终止后备，等待执行后才结束取消／超时；真实忽略 SIGTERM 的后代回归通过。
4. 实际迁移发现 PostgreSQL 对 `CREATE SCHEMA IF NOT EXISTS` 仍要求数据库 CREATE：迁移改用初始化已建的 schema，未提升账号权限。确认首轮 0 步且无业务表后，以固定 `migrate resolve --rolled-back` 恢复失败记录，再执行迁移；未 reset。失败记录保留为 rolled back，另有一条成功记录。
5. 数据库测试适配 Prisma 7 实际错误结构：严格匹配 KnownRequestError/P2010 和 `driverAdapterError.cause.originalCode`，不放宽为任意拒绝；元数据检查不要求 public schema USAGE。
6. 提交检查发现原 `storage/` 忽略规则也覆盖源码：改为 `/storage/`，确认运行目录仍忽略、src/storage 可提交。质量复核通过。
7. Git 自动换行转换会改变已带 SHA256 引用的许可归档和清单字节；对四个确切审计文件设置 `-text`，重新暂存原始字节，逐文件确认索引 blob 与工作树一致。旧归档正文及已有摘要不变，修复检出后摘要不一致问题。
