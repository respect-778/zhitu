versions, package NOTICE files, embedded vendor license files, and literal license

copyright notices. Compressed license files are decompressed without editing.

is EPL-2.0, not MIT. Existing React copyright wording is retained verbatim.

proof that every compiled/WASM bundle's internal component has a complete license

code, native engine dependencies, removed notices, and unavailable upstream notices
cannot be reconstructed from npm manifest declarations. T22 must verify the real
