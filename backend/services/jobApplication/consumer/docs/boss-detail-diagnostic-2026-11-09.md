# BOSS 详情读取中断：2026-11-09 实测记录

## 已确认的事实

- 用户页面显示：列表读取 1 页、返回 30 条、保留 17 条；完成 4 个详情后停止。
- 同一个已登录 Chrome 中，BOSS 原生搜索页可以打开。原生列表响应 HTTP 200、业务码 0、15 条、`hasMore: true`，原生首条详情响应 HTTP 200、业务码 0。
- 单次诊断按助手现有 GET 列表请求读取 `agent开发 / 全国 / 实习`，返回 HTTP 200、业务码 0、30 条、`hasMore: true`。
- 对月薪估算区间与 4000–8000 元有重叠的岗位，按薪资排序逐条读取详情。前 4 条为 HTTP 200、业务码 0，岗位身份核对一致；第 5 条为 HTTP 200、业务码 37，原文为“您的环境存在异常.”。
- 收到该拒绝后立即停止，没有继续请求或尝试绕过验证。

## 原因与边界

本次中断是 BOSS 对详情请求的环境校验拒绝；不能将它解释为只有 17 条岗位、已经读完所有页，或必然是用户退出登录。服务端没有说明具体校验规则，因此不能断言由哪一个浏览器特征、请求频率或账号条件触发。

当前执行顺序是“列表一页 → 该页详情 → 下一页”。详情接口明确拒绝时，程序暂停整轮读取，因而后续页未取得。此前“正文成功、补充 HTML 失败可继续”的修复不适用于本次详情接口本身被拒绝。

## 本次修改

`extension/detail.js` 保留 HTTP 状态及数字业务码；HTTP 429 明确提示请求过频；业务码 37 且服务端明确提到环境异常时，显示环境校验拒绝。其他非零业务码不再一概提示登录失败。错误文本不包含岗位访问令牌、账号字段或原始响应数据。保持失败即暂停，不增加自动重试。

本地助手版本更新为 `0.4.3-local`，通过已有空闲更新机制载入补丁；这只是诊断与提示修正，不能解除 BOSS 的访问限制，也不能据此声称真实搜索已经完整完成。

## 验证

新增合成响应测试复现旧错误文本丢失 HTTP/业务码的问题，再验证 429、普通非零码、明确环境异常三种结果。真实扩展链路继续验证同浏览器搜索、岗位身份、字段读取和空闲自动更新。网络诊断只保留上述状态摘要，不记录 Cookie 或 securityId。

最终提示补丁的 4 项隔离测试通过（详情错误分类、搜索页连接选择、空闲更新、扩展消息边界）。真实扩展链路在首次补丁后单独验证通过；最终修改仅新增明确环境异常的提示分支，已包含在上述隔离测试中。测试端口被另一项验证任务使用时，没有终止其进程或修改共享配置。
