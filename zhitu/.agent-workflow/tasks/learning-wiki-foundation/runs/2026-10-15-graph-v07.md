# Graph v0.7 implementation evidence

Scope: the current learning-planning 2D graph, based on workspace-root intent.md/spec.md v0.7. Existing uncommitted frontend changes were preserved. No AI-assistant, model-tool, backend or database changes were made.

## Reproduced failures

Command: `python tests/path-graph-ui.py` against an isolated Vite server with intercepted workspace APIs and six synthetic notes.

- All three SVG icons were 8.5 CSS px left of their button centers. The old percentage rule targeted every descendant span, including Ant Design icon wrappers.
- Node radii counted incoming plus outgoing edges instead of distinct incoming source notes.
- Hover dimmed direct neighbors along with unrelated nodes; unrelated node alpha was 0.06.
- Incident lines changed from 1px to 1.8px; unrelated lines became 0.5px.
- The visible node-to-label gap was approximately -0.45px at rest instead of 6px.
- Merely updating React hover/tooltip state did not reliably repaint a cooled Canvas.

## Implemented

- Extracted KnowledgeGraph from EditorArea, with an isolated model and scoped control styles.
- Incoming counts deduplicate source IDs; A→B increases B only, self/missing references do not count; logarithmic radii range from 4 to 10 world units.
- Stable-ID one-hop hover targets distinguish accent, preserved neighbors and background masking. Edge targets are based on incidence, not whether both endpoints happen to be neighbors.
- Background colors mix toward the current theme surface; direct neighbors and local labels keep their original colors. All painted edges remain 1 CSS px across hover and zoom.
- Visible glyph bounds define the 6px resting gap. Hover moves the label 4px and adds at most 1px to the circle's screen radius, giving a 9px final gap.
- Hover opens a finite 120ms paint window. It closes only after the terminal values have actually been painted. Idle hit testing remains enabled; no nodeRelSize jitter or permanent forced redrawing is used.
- The zoom controller merges inputs into one cancellable target, keeps the pointer anchor and clamps progress to [0,1]. Browser evidence caught negative first-frame progress; the clamp removes its slight reverse zoom.
- Desktop controls: 166×42px outer box, three 32×32px buttons, 16px SVGs, 48px percentage cell, 4px padding/gaps. Touch controls: 202×54px with 44px buttons.

## Boundaries

- The current frontend receives a complete user workspace and its resolved Wiki bindings. It computes counts from that complete dataset. A future truncated/server-filtered graph still needs the separately planned authorized statistics endpoint.
- Current graph links are resolved Wiki links. Source-snapshot and independent topic-relation persistence, server-enforced ACL and real Agent integration remain outside this UI slice.
- The fixed 500/2000-node performance targets and real browser 125%/150% zoom are not claimed as measured here; DPR 1.5 is separately identified above.
- The agent-workflow CLI was unavailable (`npm could not determine executable`). Existing task files and this evidence record were maintained directly; no substitute CLI was downloaded.
